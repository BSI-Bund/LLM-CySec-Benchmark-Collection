# Contributing

Contributions to this repository are welcome. The goal is to maintain an accurate and up-to-date overview of benchmarks for evaluating large language models in the cybersecurity context.

## How to Contribute

You can contribute by:

- Adding a relevant cybersecurity benchmark that is not yet included.
- Updating information about an existing benchmark.
- Correcting inaccurate or outdated information.
- Improving descriptions, references, categorisation, or documentation.

## Adding a Benchmark

When proposing a new benchmark, please provide enough information to make the entry verifiable and consistent with the existing repository structure. Where applicable, include:

- Benchmark name
- Short description
- Cybersecurity category and topic
- Dataset information
- Publication or release date
- Link to the benchmark, publication, or official repository

Please prefer primary sources, such as the original publication, official project website, or official repository.

## Submitting Changes

1. Fork the repository and create a branch for your changes.
2. Make your changes while following the existing structure and formatting.
3. Ensure that links and references are valid and that factual information can be verified.
4. Submit a pull request with a short description of the proposed changes.

For small corrections or suggestions, you may also open an issue instead of submitting a pull request.

## Scope

Contributions should be relevant to benchmarking large language models or related AI systems in the cybersecurity context. Inclusion in the repository is intended to document relevant benchmarks and does not constitute an endorsement of a benchmark, methodology, or associated project.

## Questions and Suggestions

If you are unsure whether a benchmark fits the scope of the repository, feel free to open an issue for discussion.

Thank you for helping keep this overview useful and up to date.
