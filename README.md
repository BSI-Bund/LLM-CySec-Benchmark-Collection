# LLM-CySec-Benchmark-Collection

This repository provides a regularly updated overview of benchmarks for evaluating large language models in the cybersecurity domain. While related work provides broader overviews of LLM benchmarks, this repository specifically focuses on benchmarks that assess offensive and defensive cybersecurity capabilities. For background on the foundations and key considerations of LLM benchmarking in cybersecurity, see our publication [Fundamentals of Benchmarking LLMs in the Context of Cybersecurity](https://www.bsi.bund.de/SharedDocs/Downloads/EN/BSI/KI/Fundamentals-LLM-Benchmarking).

The repository consists of two main parts:

- [Benchmark overview](benchmark_overview.md): A structured overview of LLM benchmarks in the cybersecurity context.
- [Benchmark descriptions](benchmark_descriptions.md): A collection of short descriptions providing additional information about each benchmark.
